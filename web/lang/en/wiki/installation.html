DeepCrate / Install

Install

DeepCrate is required on the server and on every client. A player without it sees neither the crates nor their screen, and gets turned away at the door.

  1. Install the mod loader recommended on the mod's CurseForge or Modrinth page, for the Minecraft version shown there.
  2. Download DeepCrate and its companion library from either page, and drop both into the mods folder.
  3. On a server, do the same in its own mods folder, then restart it once so it writes its settings out.
  4. Start the game. config/oas/deepcrate.json appears on the first launch and is rewritten on every one after it.

The versions are not written here

No compatibility table on this page, on purpose. Both shops show live which versions the file you are downloading accepts, and a frozen copy here would go wrong without anyone noticing.

What can sit beside it

The mod asks for nothing beyond the loader and its companion library. The usual optimisation mods run alongside it, with one exception: while lithium is installed a crate answers 64 a slot to automation, and hopper filling stops at that number. The hopper page covers why, and how to take the decision back.

Taking the mod out

A world saved with DeepCrate keeps its crates in the save file. Removing the mod makes the blocks and whatever they held disappear. Empty the crates first, or keep a copy of the world.
