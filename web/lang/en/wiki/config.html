DeepCrate / Settings file

Settings file

Everything is decided in config/oas/deepcrate.json, written on the first launch and rewritten on every one after, so an option added by an update shows up there by itself.

OptionWhat it decidesDefault
crate.baseCapacity what a slot holds with no capacity module, from 1 to 32,767 64
crate.limitAutomationWithLithium whether a crate answers 64 to automation while lithium is installed true
crate.maxRowsPerPage rows on one page before the screen splits, from 1 to 6 4
crate.rowModuleStackLimit row modules one cell accepts, from 1 to 20 16
screen.abbreviateAbove the count past which a slot shows 2k instead of 2048 999

A value outside its range is pulled back in

Every option has a range, and a value outside it is pulled to the nearest bound. The corrected value is what stays on disk, so the file always says what the game is actually using.

Who reads what

The first four are read on the server and count for all of its clients. The fifth is read where the screen is drawn, so it belongs to whoever is looking: two players on the same server can carry two different abbreviation thresholds.

The oas folder

The file lives under config/oas/ rather than at the root of the config folder. That is the author's namespace, so every mod by the same hand groups together instead of scattering.

Other mods' options

A mod plugging into DeepCrate writes its own options into this same file, under its own name, with its own bounds. Nothing separate to maintain, and a server owner still has one file to read. Both calls are on the addon page.
