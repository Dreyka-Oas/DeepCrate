DeepCrate / o.a.s

o.a.s

Two Minecraft mods written by the same hand, with the same habits and the same refusal to decide anything on the installer's behalf.

Where the name comes from

The config folder. Every mod out of this workshop drops its options into config/oas/, one file each, so a server running two of them finds them side by side instead of scattered through the root. It started there and stayed as a signature.

What the two mods share

A number written into the code is a number decided for everyone. Tiers, capacities, distances, delays: anything a server owner might reasonably want otherwise is read from the config file, inside a range that pulls an absurd value back to something playable rather than taking the server down with it.

Nothing a player reads lives in the Java. The two language files, en_us and fr_fr, carry the same keys, and a line added on one side and forgotten on the other is caught before release. The sites follow the same rule, two complete trees and no generator between them.

A mod that does not open up is a mod you replace instead of extending. Each one publishes an entry point: enough to add a tier, a creature, a rule, without patching anything and without asking me first. DeepCrate's twelve points show what that looks like.
